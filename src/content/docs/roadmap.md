# Public Roadmap

High-level milestones for Syn_OS beyond v111.0.0 "Last Light" (1.0 GA).

---

## v112.0.0 — "Ember Ascendant" (Planned Q3 2026)

- [ ] Kernel upgrade to Linux 7.2 with Rust-for-Linux 0.16
- [ ] GRIMOIRE 2.0: 150+ labs, adaptive difficulty, live CTF integration
- [ ] ALFRED consciousness daemon: v2 rewrite in pure Rust
- [ ] ARCANUM mesh: peer-to-peer sync for offline GRIMOIRE play
- [ ] Improved installer with guided partitioning and Btrfs snapshots

## v113.0.0 — "Phoenix Rising" (Planned Q4 2026)

- [ ] ARM64 support for Raspberry Pi 5 and mobile form factors
- [ ] Container-native boot with systemd-nspawn and Podman
- [ ] Quantum-safe TLS 1.3 with hybrid Kyber/X25519 key exchange
- [ ] Synaptic Shell: AI-augmented Zsh replacement

## v114.0.0 — "Neural Overwatch" (Planned Q1 2027)

- [ ] On-device LLM inference via llama.cpp integration
- [ ] GRIMOIRE auto-tutor: AI-generated lab hints and walkthroughs
- [ ] Synaptic OS for Steam Deck and handheld gaming devices
- [ ] Zero-trust networking baked into every service by default

## v115.0.0 — "Singularity" (Long-term Vision)

- [ ] Full desktop environment replacement (no GNOME/KDE dependency)
- [ ] Distributed GRIMOIRE mesh across ARCANUM nodes
- [ ] Post-quantum identity: QR-PKC everywhere
- [ ] Self-healing kernel via formal verification and runtime patching

---

> **Note:** This roadmap is public-facing and subject to change. Milestones are driven by community feedback, security research priorities, and the Syn_OS contributor community.
